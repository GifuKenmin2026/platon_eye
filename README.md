# プラトンの眼（Ὁ ὀφθαλμὸς τοῦ Πλάτωνος）

物を撮ると、写真の中の物がモザイクで覆われ、その物が分有する「イデア」の1語と辞書風の定義が現れる展示システムです。

- **観測**：身の回りの物を撮り、イデアを図鑑（巻物）に収める
- **探究**：お題のイデアを分有する物を、90秒以内に探して撮る

Windows PC ＋ USB カメラ ＋ モニター ＋ マウスとキーボードで動きます。

---

## 1. はじめの準備（1回だけ）

1. **Python を入れる**
   https://www.python.org/downloads/ から Python 3.10 以上を入れます。
   インストール画面の最初で「Add python.exe to PATH」にチェックを入れてください。
2. **このフォルダの `setup.bat` をダブルクリック**
   OpenCV と NumPy が入り、`.env` ファイルが作られます。
3. **Gemini の API キーを入れる**（下の「2」）
   キーが無くても「お試しモード」で全部の流れを確かめられます。

## 2. Gemini の API キーの取り方

1. https://aistudio.google.com/apikey を開き、Google アカウントでログイン
2. 「Get API key」→「Create API key」でキーを作る
3. キーをコピーし、このフォルダの `.env` をメモ帳で開いて貼る

   ```
   GEMINI_API_KEY=ここに貼ったキー
   ```

4. 保存して `start.bat` を起動し直す

キーは他の人に見せないでください。`.env` は配布や共有に含めないでください。

## 3. 起動と終了

- **起動**：`start.bat` をダブルクリック
  サーバーの黒い窓が開き、ブラウザ（Chrome。無ければ Edge）が全画面で開きます。
- **初回だけ**：ブラウザがカメラの使用許可を聞いてきたら「許可」を押します。
- **終了**：ブラウザは `Alt + F4`。サーバーは黒い窓で `Ctrl + C` か、窓を閉じます。

サーバーの窓には、撮るたびに「物 → 【イデア】」と処理時間が出ます。

## 4. 操作

| 画面 | キー | 動き |
|---|---|---|
| タイトル | `1` / `2` / `Z` | 観測 / 探究 / 図鑑 |
| 観測：撮影 | `Space` または `Enter` | 撮影 |
| | `Z` / `Esc` | 図鑑 / タイトルへ |
| 観測：結果 | `Y` / `N` | 図鑑に保存 / 保存せず撮影へ |
| 探究：お題 | `Space` / `Esc` | 始める / タイトルへ |
| 探究：探す | `Space` / `Esc` | 撮影 / やめる（記録なし） |
| 探究：はずれ | `Space` | また探す |
| 探究：達成 | `Y` / `N` | 図鑑に保存 / タイトルへ |
| 図鑑 | ホイール、`←` `→` | 巻物を送る。札を押すと詳しく読める |
| | `F` | 検索欄へ（語・読みで探す。ひらがな・カタカナどちらでも） |
| | `Esc` | 検索を消す。もう一度でタイトルへ |
| 失敗画面（影しか見えませんでした） | 何かキー | 撮影画面へ戻る |

マウスでも、画面のボタンを押して同じ操作ができます。

## 5. プラトンの写真を入れる（1回だけ）

1. https://commons.wikimedia.org/wiki/File:Plato_Silanion_Musei_Capitolini_MC1377.jpg を開く
2. 画像の下の「Download」から、800px 前後の大きさを選んで保存する
3. ファイル名を `plato.jpg` にして、`web\img` フォルダに入れる

写真が無くても動きます（写真の枠ごと出ません）。画面には「Photo: Marie-Lan Nguyen / Wikimedia Commons, CC BY 2.5」と表記を出しています。これはこの写真を使う決まりなので、消さないでください。

## 5-2. カメラの選び方

タイトル画面の下の「カメラ」で、プラトン像の中の USB カメラを選びます。選んだカメラは次から自動で使われます。

## 6. 探究のお題を変える

`web/quests.json` をメモ帳で開いて編集します（文字コードは UTF-8 のまま保存）。

```json
{"word": "庇護", "reading": "ひご", "greek": "σκέπη", "examples": ["上着", "傘", "帽子"]}
```

- `word`：お題の語、`reading`：読み、`greek`：古代ギリシャ語（無ければ `""`）
- `examples`：時間切れの時に見せる「当たりの例」を3つ

会場で見つかる物で当たる語にしてください。

## 7. 図鑑とランキングを消す（展示の終わりなど）

- **図鑑**：図鑑の画面で「全部消す」。1件だけなら札を開いて「この記録を消す」
- **探究のランキング**：タイトル画面で `Shift + Delete`

どちらも確認が出ます。図鑑とランキングは、そのPCのブラウザの中に保存されています。

## 8. 困った時

| 症状 | 直し方 |
|---|---|
| 「カメラが見つかりません」 | USB を差し直す。タイトルの「カメラ」で選び直す。ブラウザのアドレスバー左の鍵マークからカメラを「許可」にする |
| 「サーバーが動いていません」 | `start.bat` を起動し直す。黒い窓を閉じていないか確認 |
| 「APIキーが使えません」 | `.env` のキーを貼り直し、`start.bat` を起動し直す |
| 「インターネットにつながっていません」 | PC のネット接続を確認 |
| 「イデアを取り出せませんでした」 | もう一度撮る。続く場合は黒い窓のメッセージを確認 |
| タイトルに「お試しモード」と出る | `.env` に API キーが入っていない |
| 文字が明朝にならない | フォントはネットから読み込みます。つながらない時は Windows の游明朝で表示されます |

## 9. しくみ

```
ブラウザ（カメラ・画面・図鑑の保存）
   │ 撮った写真
   ▼
Python サーバー（server/app.py）
   1. Gemini … 写真の主役の物を1つ選び、物を囲む四角と名前を返す
   2. OpenCV … 四角の中を GrabCut で切り抜き、四角と合わせた範囲を
                物の大きさに合わせたマスのモザイクで覆う
   3. Gemini … その物が分有するイデアと、辞書風の定義（探究ではお題の判定も）
   │
   ▼
ブラウザがモザイクの中央に白い明朝で語を描く
```

| フォルダ | 中身 |
|---|---|
| `server/` | サーバー（`app.py` 起動、`vision.py` 画像処理、`gemini.py` Gemini 通信、`pipeline.py` 流れ） |
| `web/` | 画面（HTML / CSS / JavaScript）、`quests.json` お題 |
| `tests/` | テスト（`python -m unittest discover -s tests -t .`） |

使っているのは Python の標準機能と OpenCV、NumPy だけです。
